Before the clock starts

Nose Calibration is a short, timed practice assessment. While you work through it, the app records how you use this assessment page, and nothing else, so researchers can study typing and navigation patterns. Read what is collected, then decide.

  • Tick the consent box, then press Start session. Nothing is recorded before that.
  • Review the question list, then solve at your own pace.
  • Finish, or press Stop recording, to end capture. Sharing is a separate, optional choice.

Share with the study organizer

Optional

Your session stays on this computer unless you complete the steps below. Signing in uploads nothing; only Encrypt and share starts an upload, and it goes to a private repository, not a public one. A receipt confirms completion; an interrupted upload may leave encrypted files in your private submission repository.

  1. Sign in to GitHub Nose Calibration has its own GitHub sign-in and does not use GitHub CLI or other GitHub logins saved on this computer. The app shows a one-time code to enter at github.com/login/device. GitHub then asks you to approve the broad repo scope, which allows reading and writing every repository your account can reach, including private ones. After you approve, the account name appears beside Sign out; check it is the account you mean to use.
  2. Encrypted on this computer The recording is encrypted here with the organizer's public key before it leaves. It is intended to be readable only with the organizer's private key.
  3. Private repository in your account A new private repository is created in your own GitHub account. It holds only the encrypted submission file. You remain its owner.
  4. Organizer gets write access to that repository GitHub personal repositories have no read-only option for collaborators, so the organizer is added as a collaborator with write access. They can read, change or delete files in that one submission repository. This does not add them to your other repositories. You can remove them from the repository's settings at any time.

Numeric metrics derived from your session may be reviewed by OpenAI Codex. Raw code, key presses and screenshots are not automatically sent to any AI model.

Not signed in to GitHub

The access token is kept in this app's memory and is not saved. Sign out or closing the app discards it here, but does not revoke the authorization on GitHub. To revoke it, open GitHub Settings › Applications › Authorized OAuth Apps and revoke Nose Calibration.
