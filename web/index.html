Before the clock starts

Nose Calibration is a short, timed practice assessment. While you work through it, the app records how you use this assessment page, and nothing else, so researchers can study typing and navigation patterns. Read what is collected, then decide.

  • Tick the consent box, then press Start session. Nothing is recorded before that.
  • Review the question list, then solve at your own pace.
  • Finish, or press Stop recording, to end capture. Sharing is a separate, optional choice.

    Earlier GitHub sharing Only if the organizer asked you to use GitHub

    Your session stays on this computer unless you finish the steps below. Signing in uploads nothing. Only Encrypt and share uploads, and only to a private repository you own. An interrupted upload may leave an encrypted file there; it is never overwritten.

    Encrypted here
    Encrypted on this computer with the organizer's public key before it leaves. It is intended to be readable only with the organizer's private key.
    One repository
    The app can reach only the repository you select: Contents read and write, Metadata read-only. Each recording is added as its own file; existing files are never replaced.
    Short-lived sign-in
    The token stays in this app's memory for at most 8 hours and is never saved. GitHub's refresh token is discarded.
    Organizer keeps write access
    Personal repositories have no read-only collaborators, so the organizer can read, change or delete files in this one repository, for this and later recordings, until you remove them. They get nothing in your other repositories. This narrows access; it does not make sharing risk-free.
